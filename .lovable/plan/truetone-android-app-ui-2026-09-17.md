# TrueTone Android App UI

## Build
- Replace the placeholder with a polished mobile-first TrueTone experience covering all 12 requested screens.
- Make the experience navigable end-to-end: login, OTP, permissions, home, call analysis, behavior check, result, blocking, history, incident detail, and profile.
- Use realistic Indian contact and incident data, with functional filters, toggles, dialogs, and bottom navigation.

## Visual direction
- Use a calm enterprise security aesthetic with deep indigo, teal safety states, amber warnings, and red high-risk states.
- Use a clean sans-serif type system, compact rounded cards, restrained shadows, strong contrast, and generous spacing.
- Give the Home Dashboard and Result screen premium visual hierarchy, including a protection status panel and animated risk gauge.

## Technical details
- Implement the flow in the existing TanStack React home route with shared screen primitives and local UI state.
- Define all color, type, shadow, and animation values as semantic tokens in the global design system.
- Add route-specific metadata and verify the finished UI at mobile and desktop widths, including the key interactions.
